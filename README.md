# AMmaterials-CS-26-27

## Commands:
- git clone <url-of-git-repository-file>
  - Clones the repository to your computer. You are still able to push
  - changes to the repository in the cloud.
- git add <name-of-files>
  - Starts tracking all files if not already tracked. Stages files specified.
- git commit -m "<name-of-commit>"
  - Commits all staged changes.
- git push
  - Pushes all new commits to the remote repository.
